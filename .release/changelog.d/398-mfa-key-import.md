- `vh secret set mfa-seal|mfa-pepper <file>` (#398) imports the export of the MFA keys on a new host, so a restored database keeps TOTP and recovery codes working with no re-enrollment. Super admins only, confirmed, audited as `secrets.mfa_key.import` (`ops::mfa_keys`); the key is checked before it is adopted (a stored TOTP seed must open, or the hash of one of the actor's own recovery codes, `--code`, must recompute), a mismatched key or a host that already has a working key is refused with nothing changed, and the key is never printed.
